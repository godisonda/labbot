# Папка работ

Здесь лежат ваши лабораторные и практические. В git попадает только этот файл:
содержимое `labs/` исключено через `.gitignore`, чтобы черновики и методички
не уезжали в публичный репозиторий.

Одна работа — одна папка:

```
labs/lab_04/
├── Задание 4.docx      # методичка или ТЗ (PDF/DOCX/TXT)
├── notes.txt           # необязательно: вариант и свои данные
├── refs/               # необязательно: образец готового отчёта
│   └── пример.docx
├── src/                # создастся само: исходный код
├── scripts/            # создастся само: скрипт графиков
├── build/              # создастся само: tex, pdf, состояние
└── reports/            # создастся само: готовые файлы
```

Папку можно назвать как угодно: `lab_04`, `Курсовая по сетям`, `network-course`.
Создать структуру: `make new lab=04`, `make new name="Курсовая по сетям"`
или кнопка «+ Новая работа» в оболочке.
